# 프로젝트 테스트 검증 산출물

이 디렉터리는 제출 시점의 백엔드·프론트엔드 자동 검증을 실행일별로 보관한다.
외부 AI·Supabase·모두싸인 호출은 포함하지 않으며, 실제 외부 연동 결과는 각 실행일의
`live-integration-summary.md`가 별도 증빙으로 연결한다.

## 최신 실행

- [2026-08-03 현재 광고성과 리포트 교체 검증](2026-08-03-current-report-replacement/SUMMARY.md)
- [2026-08-03 교체 전 제출 후보 자동 검증](2026-08-03-submission-candidate/SUMMARY.md)
- [2026-08-03 최초 전체 자동 검증](2026-08-03/SUMMARY.md)

## 원칙

- 일반 테스트는 외부 Adapter를 `mock`으로 고정한다.
- live 결과와 오프라인 결과를 같은 성능 수치로 합치지 않는다.
- 실패하거나 실행하지 않은 검증은 통과로 기록하지 않는다.
- 새 실행은 기존 산출물을 덮어쓰지 않고 날짜별 디렉터리에 추가한다.
- API key, 인증 헤더, 계약 원문, 공개 토큰, 서명 URL, 모델 원시 응답을 저장하지 않는다.
