# MVP 제품 범위

## 반드시 완성할 흐름

`계약서 업로드 → 조건 추출 → 근거 기반 검토 → 1회 조정 → 합의서 → 양측 전자서명 → 산출물 증빙 → 만료 확인`

## P0

- PDF 업로드와 핵심 조건 추출
- 사용자가 이해한 조건 5문항
- 기간·금액·해지·환불 불일치
- 빈칸·산출물·촬영 안전·책임 확인 신호
- 원문 페이지·문장·확신도가 연결된 조항 카드
- 원안 수용·절충안·요청안 문구
- 대행사의 수락·거절·역제안 1회
- 최대 4개 조항의 변경·확인 합의서
- 모두싸인 상태와 중복 안전 웹훅
- 감사 타임라인, 산출물 한 건, 만료 일정, 최소 대시보드

## 비목표

- 법률 자문 또는 사기·위법성 판정
- 실제 결제·송금
- 광고 성과·매출 측정
- 반복 자동 협상
- 다국어 UI
- 게시물 URL의 실제 존재 여부 자동 검증
