| 파일 | 권장 화면 |

## 캡처 가이드

- 가능하면 모든 캡처를 같은 가로세로 비율로 맞춥니다. 데스크톱은 `1440×900` 또는
  `16:10`, 모바일은 동일한 기기 프레임 크기를 권장합니다.
- 실제 계약 전문, 실명, 이메일, 전화번호, API 키, 공개 토큰, 서명 링크는 포함하지 않습니다.
- 운영 화면을 촬영할 때는 가상 계약과 비식별 데모 데이터만 사용합니다.
- 캡처를 추가한 뒤 루트 `README.md`의 해당 `img src`를 `placeholder.svg`에서 실제 PNG
  파일명으로 바꿉니다.
- 이미지 용량이 크면 글자가 읽히는 범위에서 PNG를 최적화합니다.
